# Hotel-project-Digilians-
                                             Hotel Booking Data Analysis & Insights

📊 Project Overview:
This project focuses on analyzing hotel booking data to uncover customer behavior, identify cancellation drivers, and generate actionable insights to support business decisions in the hospitality industry.

🎯 Objectives:
Analyze booking patterns and customer segments
Identify key factors influencing booking cancellations
Evaluate pricing and revenue performance
Provide data-driven recommendations to improve operations

🛠️ Tools & Technologies:
Python (Pandas, NumPy, Matplotlib, Seaborn)
SQL
Power BI
Orange (Data Mining)

🔍 My Role:
I contributed to: 
1.Performing Exploratory Data Analysis (EDA): My responsibilities included analyzing relationships within the dataset, such as examining category-to-category interactions, assessing how numerical variables change across different categories, and identifying correlations between numeric features. I also performed visual analysis using heatmaps to better understand multivariate relationships, and investigated rare categories that could impact model performance or insights.
2.Assisted in building a dashboard using Power BI


📈 Key Insights
High cancellation rate (~37%) impacting revenue
Majority of bookings come from online travel agents
Low-performing room types and segments affecting efficiency
Strong variation in revenue across customer segments

💡 Recommendations
Improve direct booking channels
Optimize room inventory and pricing strategies

📊 Dashboard Features
KPIs: Total bookings, cancellations, ADR, revenue
Interactive filters (hotel type, segment, date)
Trend analysis for bookings vs cancellations

🚀 Outcome
This project demonstrates how data analysis can:
Reduce cancellations
Improve revenue strategies
Support operational decision-making
